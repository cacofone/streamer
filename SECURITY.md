# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **admin@cacofone.com** with a description of the issue, the affected version and steps to reproduce. You can also use GitHub's private vulnerability reporting on this repository.

I will acknowledge your report as soon as I can and keep you informed while it is fixed. This is a hobby project run by one person, so there are no guaranteed response times.

## Supported versions

Only the latest release receives security fixes.
